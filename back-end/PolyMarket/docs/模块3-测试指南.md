## 🚀 快速开始

### 1. 启动服务

```bash
cd back-end/PolyMarket
go run main.go
```

服务将在 `http://localhost:8888` 启动

### 2. 初始化数据库

```bash
# 方法1: 使用MySQL命令行
mysql -u root -p123456 polymarket < scripts/module3_init_db.sql

# 方法2: 使用MySQL客户端
# 打开MySQL客户端，执行scripts/module3_init_db.sql中的SQL语句
```

### 3. 获取JWT Token

#### 步骤1: 获取Nonce

```bash
curl -X POST http://localhost:8888/api/v1/auth/nonce \
  -H "Content-Type: application/json" \
  -d '{
    "wallet_address": "0x742d35Cc6634C0532925a3b844Bc9e7595f0bEb"
  }'
```

响应示例：
```json
{
  "code": 0,
  "msg": "success",
  "data": {
    "nonce": "Welcome to PolyMarket!\n\nClick to sign in and accept the Terms of Service.\n\nThis request will not trigger a blockchain transaction or cost any gas fees.\n\nWallet address:\n0x742d35cc6634c0532925a3b844bc9e7595f0beb\n\nNonce:\nabc123def456",
    "expires_at": "2026-01-19T10:05:00Z"
  }
}
```

#### 步骤2: 使用MetaMask签名

在浏览器中使用MetaMask对nonce进行签名，获得signature。

#### 步骤3: 登录获取Token

```bash
curl -X POST http://localhost:8888/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{
    "wallet_address": "0x742d35Cc6634C0532925a3b844Bc9e7595f0bEb",
    "signature": "0x..."
  }'
```

响应示例：
```json
{
  "code": 0,
  "msg": "success",
  "data": {
    "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "refresh_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "expires_in": 86400
  }
}
```

#### 步骤4: 设置环境变量

```bash
# Linux/Mac
export TOKEN="eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
export API_URL="http://localhost:8888/api/v1"

# Windows PowerShell
$TOKEN = "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
$API_URL = "http://localhost:8888/api/v1"
```

### 测试1: 创建订单

```bash

  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \

    "order_type": 0,
```

## 🐛 常见问题

### 问题1: 401 Unauthorized

**原因**: Token无效或已过期

**解决**: 重新登录获取新的Token

### 问题2: 404 Market not found

**原因**: 市场不存在

**解决**: 先创建测试市场，或使用已存在的market_id

### 问题3: 400 Invalid parameters

**原因**: 请求参数不正确

**解决**: 检查参数类型和取值范围
