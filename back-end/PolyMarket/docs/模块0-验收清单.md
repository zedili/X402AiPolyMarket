## 🐛 常见问题排查

### 问题 1: 数据库连接失败

**错误信息**: `failed to connect database`

**解决方案**:
1. 检查 MySQL 是否启动：`mysql -u root -p`
2. 检查配置文件中的密码是否正确
3. 检查数据库是否已创建：`SHOW DATABASES;`

### 问题 2: Redis 连接失败

**错误信息**: `failed to connect redis`

**解决方案**:
1. 检查 Redis 是否启动：`redis-cli ping`
2. 检查 Redis 端口是否正确（默认 6379）
3. 检查 Redis 密码配置

### 问题 3: 端口被占用

**错误信息**: `bind: address already in use`

**解决方案**:
1. 修改配置文件中的端口号
2. 或者关闭占用 8888 端口的程序

### 问题 4: 依赖下载失败

**错误信息**: `go get: timeout`

**解决方案**:
```bash
# 设置 Go 代理
go env -w GOPROXY=https://goproxy.cn,direct
```
