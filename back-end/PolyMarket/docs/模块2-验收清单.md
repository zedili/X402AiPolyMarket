## 🐛 常见问题排查

### 问题 1: 市场列表为空

**原因**: 新创建的市场audit_status为0（待审核），不会在列表中显示

**解决方案**:
```sql
UPDATE markets SET audit_status = 1, status = 1 WHERE id = 1;
```

### 问题 2: 创建市场失败

**错误信息**: `Invalid category`

**解决方案**: 确保category为以下之一：CRYPTO, TECH, STOCKS, POLITICS, SPORTS, SCIENCE

### 问题 3: 时间格式错误

**错误信息**: `Invalid end_time format`

**解决方案**: 使用RFC3339格式，例如：`2025-12-31T23:59:59Z`
