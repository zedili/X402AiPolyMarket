## 🐛 常见问题排查

### 问题 1: gorilla/mux 未安装

**错误信息**: `cannot find package "github.com/gorilla/mux"`

**解决方案**:
```bash
go get -u github.com/gorilla/mux
go mod tidy
```

### 问题 2: 数据库表不存在

**错误信息**: `Table 'polymarket.auth_nonces' doesn't exist`

**解决方案**:
```bash
mysql -u root -p < scripts/module1_init_db.sql
```

### 问题 3: JWT 签名验证失败

**错误信息**: `Invalid or expired token`

**解决方案**:
1. 检查配置文件中的 AccessSecret 是否正确
2. 确保 Token 没有过期
3. 确保 Authorization 头格式正确：`Bearer {token}`

### 问题 4: Web3 签名验证失败

**错误信息**: `Invalid signature`

**解决方案**:
1. 确保使用正确的 nonce 进行签名
2. 确保钱包地址与签名地址一致
3. 确保签名格式正确（0x开头的十六进制）
