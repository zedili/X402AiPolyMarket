# 前端业务功能总览

## 项目简介

AI Predict Market 是一个基于 AI 预测的去中心化预测市场平台，用户可以通过钱包连接进行交易，查看 AI 预测结果，管理投资组合等。

## 核心业务模块

### 1. 首页模块 (`/`)
- **市场列表展示**：展示所有已审核的市场
- **AI 预测集成**：实时获取并展示 AI 预测结果
- **搜索与筛选**：支持按分类、关键词搜索
- **排序功能**：按成交量、创建时间、结束时间排序
- **分页功能**：支持分页浏览
- **粒子特效**：首屏粒子背景效果

### 2. 市场模块 (`/markets`)
- **市场详情页** (`/markets/[id]`)：展示市场详细信息、交易表单、AI 预测卡片
- **创建市场** (`/markets/create`)：用户创建新的预测市场

### 3. 投资组合模块 (`/portfolio`)
- **持仓管理**：查看当前持仓、盈亏情况
- **订单管理**：查看订单列表、订单状态
- **交易历史**：查看历史交易记录
- **交易统计**：查看交易统计数据

### 4. 用户模块
- **个人资料** (`/profile`)：查看和编辑个人信息、统计数据
- **排行榜** (`/leaderboard`)：查看收益排行榜、平台统计

### 5. 钱包模块 (`/wallet`)
- **余额查询**：查看钱包余额（USDC、Token）
- **交易流水**：查看钱包交易记录

### 6. 通知模块 (`/notifications`)
- **通知列表**：查看系统、交易、结算等通知
- **通知筛选**：按类型、已读/未读筛选

### 7. 管理员模块 (`/admin`)
- **市场审批** (`/admin/markets`)：审批待审核的市场、强制结算

## 技术特性

### 认证与授权
- **钱包自动登录**：连接钱包后自动触发后端登录流程
- **JWT Token 管理**：自动刷新 Token，管理登录状态
- **权限控制**：基于钱包地址的管理员权限判断

### UI/UX 特性
- **主题切换**：支持亮色/暗色主题
- **页面动画**：使用 framer-motion 实现页面过渡动画
- **响应式设计**：支持移动端和桌面端
- **加载状态**：统一的加载和错误状态处理

### AI 集成
- **流式预测**：实时获取 AI 预测结果
- **预测展示**：展示预测值、置信度、建议
- **AI Loading**：专门的 AI 加载动画

## 页面路由结构

```
/                    # 首页（市场列表）
/markets/[id]        # 市场详情页
/markets/create      # 创建市场
/portfolio           # 投资组合
/profile             # 个人资料
/leaderboard         # 排行榜
/wallet              # 钱包
/notifications       # 通知
/admin/markets       # 管理员审批中心
```

## 数据流

1. **市场数据流**：后端 API → `marketApi` → 页面组件 → UI 展示
2. **AI 预测流**：DeepSeek API → `aiApi` → 流式解析 → 实时更新 UI
3. **用户认证流**：钱包连接 → `useWalletAuth` → 后端登录 → Token 存储
4. **交易数据流**：用户操作 → API 调用 → 后端处理 → 状态更新

## 状态管理

- **认证状态**：`useAuth` hook 管理用户登录状态
- **API 调用**：`useApi` hook 统一处理 API 请求和状态
- **钱包状态**：RainbowKit/Wagmi 管理钱包连接状态
- **主题状态**：`ThemeContext` 管理主题切换

## 依赖的主要库

- **Next.js 14**：React 框架
- **RainbowKit/Wagmi**：钱包连接
- **framer-motion**：动画库
- **Shadcn UI**：UI 组件库
- **Tailwind CSS**：样式框架
- **Axios**：HTTP 客户端
- **tsparticles**：粒子效果
