# 交易功能详细说明

## 功能模块

### 1. 投资组合页面

**路径**：`/portfolio`

**文件**：`/app/portfolio/page.tsx`

#### 功能描述

展示用户的投资组合信息，包括持仓、订单、交易历史和统计数据。

#### Tab 结构

使用 `Tabs` 组件实现四个标签页：

1. **持仓 (Positions)**
   - 显示当前持仓列表
   - 使用 `PositionList` 组件

2. **订单 (Orders)**
   - 显示订单列表
   - 使用 `OrderList` 组件

3. **交易历史 (History)**
   - 显示历史交易记录
   - 使用 `TradeHistory` 组件

4. **统计 (Stats)**
   - 显示交易统计数据
   - 使用 `TradingStats` 组件

#### 技术实现

**Tab 切换动画**
```typescript
const [activeTab, setActiveTab] = useState('positions');
const [sliderPosition, setSliderPosition] = useState({ left: 0, width: 0 });

// 滑动指示器动画
<motion.div
  className="absolute bottom-0 h-[2px] bg-primary rounded-full"
  animate={{
    x: sliderPosition.left,
    width: sliderPosition.width,
  }}
  transition={{
    type: "spring",
    stiffness: 400,
    damping: 35,
    mass: 0.8,
  }}
/>
```

**内容切换动画**
```typescript
<AnimatePresence mode="wait">
  <motion.div
    key={activeTab}
    initial={{ opacity: 0, y: 20 }}
    animate={{ opacity: 1, y: 0 }}
    exit={{ opacity: 0, y: -20 }}
    transition={{ duration: 0.3 }}
  >
    {activeTab === 'positions' && (
      <TabsContent value="positions">
        <PositionList />
      </TabsContent>
    )}
    {/* ... 其他 tabs */}
  </motion.div>
</AnimatePresence>
```

**关键优化**
- 使用条件渲染避免内容重复加载
- 滑动指示器使用 GPU 加速动画
- Tab 切换时内容淡入淡出

### 2. 持仓列表组件

**文件**：`/src/components/PositionList.tsx`

#### 功能描述

展示用户当前的所有持仓，包括：
- 市场信息
- 持仓方向（YES/NO）
- 持仓份额
- 平均成本
- 当前价格
- 未实现盈亏
- 已实现盈亏（如果已结算）

#### 数据获取

**API 调用**
```typescript
const { data, loading, error, execute } = useApi(tradeApi.getPositionList);

useEffect(() => {
  execute({ status: 'active' }); // 或 'settled'
}, [execute]);
```

**数据格式**
```typescript
interface PositionInfo {
  id: number;
  market_id: number;
  market_question: string;
  market_status: number;
  position: number; // 0-NO, 1-YES
  position_name: string;
  shares: number;
  avg_price: number;
  total_cost: number;
  current_price: number;
  current_value: number;
  unrealized_pnl: number;
  unrealized_pnl_pct: number;
  realized_pnl: number;
  is_settled: boolean;
  settlement_value?: number;
  created_at: string;
}
```

#### 显示内容

1. **持仓卡片**
   - 市场问题
   - 持仓方向标签（YES/NO）
   - 持仓份额
   - 平均成本价格
   - 当前价格
   - 盈亏金额和百分比

2. **状态标识**
   - 活跃持仓：显示未实现盈亏
   - 已结算持仓：显示已实现盈亏

### 6. 创建订单表单

**文件**：`/src/components/CreateOrderForm.tsx`

#### 功能描述

在市场详情页使用，允许用户创建买入/卖出订单。

#### 表单字段

- **订单类型**：买入 / 卖出（单选）
- **持仓方向**：YES / NO（单选）
- **数量**：输入数字
- **价格**：显示当前价格（可手动调整）
- **滑点容忍度**：可选，默认值

#### 技术实现

**表单提交**
```typescript
const handleSubmit = async (e: React.FormEvent) => {
  e.preventDefault();

  if (!isAuthenticated) {
    toast.error('请先登录');
    return;
  }

  const payload: CreateOrderRequest = {
    market_id: marketId,
    order_type: orderType, // 0-买入, 1-卖出
    position: position, // 0-NO, 1-YES
    amount: parseFloat(amount),
    price: parseFloat(price),
    slippage: slippage ? parseFloat(slippage) : undefined,
  };

  await execute(payload);
};
```

**成功处理**
- 显示成功提示
- 刷新订单列表
- 刷新持仓列表

## API 集成

### 获取持仓列表

**接口**：`GET /trade/positions`

**参数**：
```typescript
{
  status?: string; // active, settled
}
```

**响应**：`PositionListResponse`

### 获取订单列表

**接口**：`GET /trade/orders`

**参数**：
```typescript
{
  page?: number;
  page_size?: number;
  market_id?: number;
  status?: number;
  order_type?: number;
}
```

**响应**：`OrderListResponse`

### 获取交易历史

**接口**：`GET /trade/history`

**参数**：
```typescript
{
  page?: number;
  page_size?: number;
  market_id?: number;
  start_time?: string;
  end_time?: string;
}
```

**响应**：`TradeHistoryResponse`

### 创建订单

**接口**：`POST /trade/order/create`

**请求**：
```typescript
{
  market_id: number;
  order_type: number; // 0-买入, 1-卖出
  position: number; // 0-NO, 1-YES
  amount: number;
  price: number;
  slippage?: number;
}
```

**响应**：`CreateOrderResponse`

### 取消订单

**接口**：`POST /trade/order/:id/cancel`

**响应**：`CancelOrderResponse`

### 获取交易统计

**接口**：`GET /trade/stats`

**响应**：`TradingStatsResponse`

## 数据流

1. **查看持仓**：
   - 用户访问 Portfolio → 调用 `getPositionList` → 展示持仓列表

2. **创建订单**：
   - 用户填写表单 → 提交 → 调用 `createOrder` → 显示结果 → 刷新列表

3. **取消订单**：
   - 用户点击取消 → 调用 `cancelOrder` → 刷新订单列表

4. **查看交易历史**：
   - 用户切换到 History tab → 调用 `getTradeHistory` → 展示历史记录

## 状态管理

- **持仓状态**：使用 `useApi` hook 管理
- **订单状态**：使用 `useApi` hook 管理
- **交易历史状态**：使用 `useApi` hook 管理
- **统计数据状态**：使用 `useApi` hook 管理

## 错误处理

- **API 错误**：显示错误提示
- **余额不足**：提示用户充值
- **订单失败**：显示失败原因
