# 首页功能详细说明

## 页面路径
`/app/page.tsx`

## 功能概述

首页是平台的核心页面，集成了市场列表、AI 预测、搜索筛选等功能，并提供粒子特效背景。

## 主要功能模块

### 1. 英雄区块 (Hero Section)

#### 功能描述
- 展示平台标题和核心价值主张
- 粒子背景特效（仅在首屏显示）
- 引导用户操作按钮

#### 技术实现
- **粒子特效**：使用 `ParticlesBackground` 组件
- **滚动控制**：监听滚动事件，当英雄区块滚出视口时隐藏粒子
- **动画效果**：使用 `useFadeInUp`、`useSlideIn` hooks 实现滚动动画

#### 关键代码位置
```typescript
// 粒子特效控制
const [showParticles, setShowParticles] = useState(true);
const heroSectionRef = useRef<HTMLElement | null>(null);

// 滚动监听
useEffect(() => {
  const handleScroll = () => {
    if (!heroSectionRef.current) return;
    const heroRect = heroSectionRef.current.getBoundingClientRect();
    if (heroRect.bottom < 0) {
      setShowParticles(false);
    } else {
      setShowParticles(true);
    }
  };
  window.addEventListener('scroll', handleScroll, { passive: true });
  return () => window.removeEventListener('scroll', handleScroll);
}, []);
```

### 3. 市场列表区 (Markets Section)

#### 3.1 市场列表获取

**API 调用**
```typescript
marketApi.getMarketList({
  page,
  page_size: pageSize,
  category: selectedCategory === "ALL" ? undefined : selectedCategory,
  search: searchQuery || undefined,
  sort,
  order: order as 'asc' | 'desc',
```

**数据状态管理**

- `total`: 总数量
- `loading`: 加载状态
- `error`: 错误信息

#### 3.2 AI 预测集成

**功能描述**
- 为每个市场实时获取 AI 预测结果
- 支持流式数据接收
- 显示 AI 加载状态

**技术实现**
```typescript
// 为每个市场获取AI预测
useEffect(() => {
  markets.forEach((market) => {
    // 如果已经有预测数据或正在加载，跳过
    if (aiPredictions[market.id] || aiLoadingStates[market.id]) {
      return;
    }

    // 如果市场已经有AI预测数据，直接使用
    if (market.ai_prediction !== undefined && market.confidence !== undefined) {
      setAiPredictions((prev) => ({
        ...prev,
        [market.id]: {
          market_id: market.id,
          prediction_value: market.ai_prediction,
          confidence: market.confidence,
          suggests: market.suggests,
        },
      }));
      return;
    }

    // 否则发起AI预测请求
    aiApi.getPredictionStream(
      market.id,
      (partialData) => {
        // 流式更新
      },
      (fullData) => {
        // 完整数据更新
      },
      (err) => {
        // 错误处理
      }
    );
  });
}, [markets]);
```

**状态管理**
- `aiPredictions`: 存储每个市场的 AI 预测结果
- `aiLoadingStates`: 存储每个市场的加载状态

#### 3.3 搜索与筛选

**搜索功能**
- 支持关键词搜索市场问题
- 搜索时重置到第一页
- 实时搜索（输入后触发 API 请求）

**分类筛选**
- 动态生成分类列表（从市场数据中提取）
- 支持 "ALL" 查看所有分类
- 切换分类时重置到第一页

**排序功能**
- **排序字段**：
  - `volume`: 成交量
  - `created_at`: 创建时间
  - `end_time`: 结束时间
- **排序方向**：
  - `asc`: 升序
  - `desc`: 降序

#### 3.4 分页功能

**功能描述**
- 每页显示 20 条数据
- 支持上一页/下一页导航
- 显示当前页数和总页数

**实现细节**
```typescript
const [page, setPage] = useState(1);
const [pageSize] = useState(20);

// 分页控件
{total > pageSize && (
  <div className="flex justify-center gap-2 pt-4">
    <Button
      variant="outline"
      disabled={page === 1}
      onClick={() => setPage(page - 1)}
    >
      上一页
    </Button>
    <span className="flex items-center px-4 text-sm text-muted-foreground">
      第 {page} 页，共 {Math.ceil(total / pageSize)} 页
    </span>
    <Button
      variant="outline"
      disabled={page >= Math.ceil(total / pageSize)}
      onClick={() => setPage(page + 1)}
    >
      下一页
    </Button>
  </div>
)}
```

## 组件依赖

- `useFadeInUp`: 滚动淡入动画
- `useSlideIn`: 滚动滑入动画

## 数据流

1. **页面加载** → 获取市场列表 → 显示市场卡片
2. **市场数据返回** → 为每个市场发起 AI 预测请求 → 更新预测数据
3. **用户操作**（搜索/筛选/排序）→ 更新查询参数 → 重新获取市场列表
4. **滚动事件** → 检测英雄区块位置 → 控制粒子特效显示/隐藏

## 性能优化

1. **粒子特效优化**
   - 使用 `useRef` 确保只初始化一次
   - 使用 `useMemo` 缓存配置选项
   - 通过 `visible` prop 控制播放/暂停

2. **AI 预测优化**
   - 避免重复请求（检查已有数据）
   - 流式更新减少等待时间
   - 错误处理避免阻塞

3. **列表渲染优化**
   - 使用 `StaggerChildren` 错开动画
   - 虚拟滚动（未来可考虑）

## 错误处理

- **API 错误**：显示错误信息，提供重试按钮
- **空数据**：显示友好提示，提供清除筛选按钮
- **加载状态**：显示骨架屏

## 响应式设计

- **移动端**：单列布局，筛选器可横向滚动
- **平板端**：两列布局
- **桌面端**：三列布局
