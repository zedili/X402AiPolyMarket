# 市场功能详细说明

## 功能模块

### 1. 市场列表展示

**位置**：首页 (`/app/page.tsx`)

**功能**：
- 展示所有已审核的市场（`status: 1`）
- 支持搜索、筛选、排序、分页
- 集成 AI 预测展示

**详细说明**：参见 `01-首页功能.md`

### 2. 市场详情页

**路径**：`/markets/[id]`

**文件**：`/app/markets/[id]/page.tsx`

#### 功能描述

展示单个市场的详细信息，包括：
- 市场基本信息（问题、描述、分类、时间等）
- 价格信息（YES/NO 价格、份额、流动性）
- AI 预测结果
- 交易表单
- 市场统计信息

#### 技术实现

**数据获取**
```typescript
const { data: market, loading, error, execute } = useApi(marketApi.getMarketDetail);

useEffect(() => {
  if (marketId) {
    execute(marketId);
  }
}, [execute, marketId]);
```

**组件结构**
- `MarketDetailContent`: 市场详情内容组件
  - 市场基本信息展示
  - 价格图表
  - AI 预测卡片
  - 交易表单
  - 市场统计

#### 关键功能点

1. **价格展示**
   - YES 价格和 NO 价格实时显示
   - 价格变化趋势图表
   - 份额和流动性信息

2. **AI 预测展示**
   - 使用 `AIPredictionCard` 组件
   - 显示预测值、置信度、建议
   - 支持流式更新

3. **交易功能**
   - 使用 `CreateOrderForm` 组件
   - 支持买入/卖出 YES/NO
   - 实时价格显示

4. **市场状态**
   - 显示市场状态（进行中/已结束/已结算）
   - 结算结果显示（如果已结算）

### 3. 创建市场

**路径**：`/markets/create`

**文件**：`/app/markets/create/page.tsx`

#### 功能描述

允许用户创建新的预测市场，提交后进入审核流程。

#### 表单字段

**必填字段**
- `question`: 市场问题（字符串）
- `category`: 分类（选择：CRYPTO/TECH/STOCKS/POLITICS/SPORTS/SCIENCE）
- `end_time`: 结束时间（日期时间选择器）

**可选字段**
- `description`: 详细描述（文本域）
- `initial_liquidity`: 初始流动性（数字）
- `tags`: 标签（逗号分隔的字符串）

#### 技术实现

**表单提交**
```typescript
const handleSubmit = async (e: React.FormEvent) => {
  e.preventDefault();

  if (!isAuthenticated) {
    toast.error('请先登录');
    return;
  }

  if (!question || !category || !endTime) {
    toast.error('请填写必填项');
    return;
  }

  const payload: CreateMarketRequest = {
    question,
    category,
    end_time: new Date(endTime).toISOString(),
  };

  if (description) {
    payload.description = description;
  }
  if (initialLiquidity) {
    payload.initial_liquidity = parseFloat(initialLiquidity);
  }
  if (tags) {
    payload.tags = tags
      .split(',')
      .map((t) => t.trim())
      .filter(Boolean);
  }

  await execute(payload);
};
```

**成功处理**
- 显示成功提示
- 跳转到首页市场列表区域 (`/#markets`)

**权限控制**
- 需要用户登录（连接钱包并完成后端登录）
- 未登录用户显示提示信息

#### 审核流程

1. 用户提交创建市场请求
2. 后端创建市场，状态为 `pending`（待审核）
3. 管理员在审批中心审核
4. 审核通过后，市场状态变为 `approved`（已审核）
5. 已审核的市场在首页显示

### 4. 市场卡片组件

**文件**：`/src/components/MarketCard.tsx`

#### 功能描述

展示市场的基本信息卡片，支持两种数据格式：
- Mock 数据格式（`Market`）
- API 数据格式（`MarketListItem`）

#### 显示内容

1. **市场基本信息**
   - 分类标签
   - HOT 标签（如果 `is_hot: true`）
   - 市场问题（最多 3 行，超出显示省略号）
   - 市场描述（最多 2 行，超出显示省略号）

2. **价格信息**
   - YES 价格（百分比）
   - NO 价格（百分比）
   - 价格趋势箭头

3. **AI 预测信息**
   - AI 预测值（0-100）
   - 置信度（0-100）
   - 建议（YES/NO）
   - AI Loading 状态

4. **市场统计**
   - 成交量
   - 结束时间

#### 技术实现

**类型适配**
```typescript
// 类型守卫函数
function isMarketListItem(market: Market | MarketListItem): market is MarketListItem {
  return typeof market.id === 'number' && 'is_hot' in market;
}

// 适配不同数据格式
const isApiFormat = isMarketListItem(market);
const yesPrice = isApiFormat ? Math.round(market.yes_price) : (market as Market).yesPrice;
```

**样式特性**
- 悬停效果（阴影、位移）
- 渐变背景
- 响应式布局

## API 集成

### 市场列表 API

**接口**：`GET /market/list`

**参数**：
```typescript
{
  page?: number;
  page_size?: number;
  category?: string;
  status?: number;
  sort?: string; // volume, created_at, end_time
  order?: string; // asc, desc
  search?: string;
  is_hot?: boolean;
}
```

**响应**：
```typescript
{
  total: number;
  page: number;
  page_size: number;
  markets: MarketListItem[];
}
```

### 市场详情 API

**接口**：`GET /market/:id`

**响应**：`MarketDetailResponse`

### 创建市场 API

**接口**：`POST /market/create`

**请求**：
```typescript
{
  question: string;
  description?: string;
  category: string;
  end_time: string; // ISO 8601
  initial_liquidity?: number;
  tags?: string[];
}
```

**响应**：
```typescript
{
  market_id: number;
  contract_address?: string;
  tx_hash?: string;
  status: string; // pending, approved
}
```

## 数据流

1. **市场列表**：
   - 用户访问首页 → 调用 `getMarketList` → 展示市场卡片
   - 用户搜索/筛选 → 更新参数 → 重新调用 API → 更新列表

2. **市场详情**：
   - 用户点击市场卡片 → 跳转到详情页 → 调用 `getMarketDetail` → 展示详情

3. **创建市场**：
   - 用户填写表单 → 提交 → 调用 `createMarket` → 跳转到首页

4. **AI 预测**：
   - 市场列表加载 → 为每个市场调用 AI 预测 API → 流式更新预测数据

## 状态管理

- **市场列表状态**：在首页组件中管理
- **市场详情状态**：使用 `useApi` hook 管理
- **创建市场状态**：使用 `useApi` hook 管理

## 错误处理

- **API 错误**：显示错误提示，提供重试选项
- **数据为空**：显示友好提示
- **权限错误**：提示用户登录或权限不足
